# scry-rs-derive

`#[derive(Reflect)]` for [Scry.Rust](https://github.com/sdaliyot/Scry.Rust). It is re-exported by
[`scry-rs`](https://crates.io/crates/scry-rs), and [`cargo scry`](https://crates.io/crates/scry-rs-cargo)
adds the derive to an app's types by itself, so apps don't depend on this crate directly.
